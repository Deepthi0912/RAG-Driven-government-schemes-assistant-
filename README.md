RAG-Driven Government Schemes Assistant

Project Overview
An AI-powered assistant designed to help Indian citizens discover and understand government schemes through natural-language conversations.The system uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from official government sources and generate context-aware responses using Google Gemini.

Problem Statement:
Information about Indian government schemes is scattered across different websites and documents. People often struggle to identify relevant schemes and understand eligibility criteria, benefits and application procedures.
This project aims to simplify access to government scheme information through an AI-powered assistant.

Key Features:
Natural-language question answering
Government scheme discovery
Eligibility criteria explanation
Benefits and required documents
Application procedure guidance
Official source references
Context-based AI responses
